# Sample data — SYNTHETIC, for demonstration and automated testing only

`sample_customer_transactions.csv` is generated by `python utils/sample_data.py`
(fixed seed 42, reproducible). It contains ~1,200 fake customers with repeated
transactions plus intentional dirt (duplicates, invalid dates, negative refunds,
outliers, missing values) so the Data Quality & Cleaning page can be exercised.

Never treat this file as real customer data. The application never mixes it with
an uploaded dataset unless the user explicitly loads it.
